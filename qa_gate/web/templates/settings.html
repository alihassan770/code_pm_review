GitHub access

Reads each client's repositories to build the knowledge base — the module list, qa/knowledge.yml and qa/scenarios/. Read-only; this app never pushes to a client repo.

Private repositories need this. GitHub answers an unauthenticated request for a private repo with the same 404 it gives for one that does not exist, so without a token a private repo looks exactly like a typo.

Create one at github.com/settings/tokens. A classic token needs the repo scope; a fine-grained token needs Contents: read-only on the repositories, and for an organisation like HSxTech the org must have approved it. Verified against GitHub before it is stored, and encrypted at rest.
